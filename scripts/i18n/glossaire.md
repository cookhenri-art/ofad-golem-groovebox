# Glossaire FR -> EN de l'interface OFAD GOLEM (groovebox)

Contexte : groovebox logicielle (16 pistes, pads, séquenceur pas à pas, synthés, effets, scènes, crossfader,
pavé vectoriel, morceau, montage audio). Interface tactile et PC. Textes COURTS (boutons, étiquettes).

Termes imposés (déjà utilisés dans la notice anglaise) :
- Écrans : PISTES TRACKS, LANCEMENT LAUNCH, SÉQUENCE SEQUENCE, SON SOUND, EFFETS EFFECTS, MIXEUR MIXER, SCÈNES SCENES, RÉGLAGES SETTINGS
  (garder la casse de la source : « Pistes » -> « Tracks », « PISTES » -> « TRACKS »)
- Grille, Morceau, Audio -> Grid, Song, Audio ; Rangée(s) -> Row(s) ; Mode morceau -> Song mode ; Boucle -> Loop
- Enr. -> Rec ; Lecture -> Play ; Arrêt -> Stop ; Maj -> Shift ; Fill, Break -> Fill, Break
- Rôles des pads : Jouer Play, Couper Mute, Scènes Scenes, Pas Step, Effacer Erase
- Ouvrir le synthé -> Open the synth ; Ouvrir l'instrument -> Open the instrument ; façade -> panel ; pédalier / pédales -> pedalboard / pedals
- Photo -> Photo ; Rappel -> Recall ; Mod. boutons -> Knob mods ; Vue live -> Live view
- Assigner à… -> Assign to… ; Libérer le bouton -> Free the knob ; Apprendre MIDI -> Learn MIDI ; bouton assignable -> assignable knob
- Accent -> Accent ; Glissé -> Slide (abrégé Gl. -> Sl.) ; Verrous -> Locks ; Verrous seuls -> Locks only ; verrouiller -> lock
- Écriture : Acide / À verrous -> Writing: Acid / Locks ; Suivre -> Follow ; Décaler -> Nudge ; Masquer / Afficher -> Hide / Show
- Éditer -> Edit ; Terminer -> Done ; Pavé actif / arrêté -> Pad active / stopped ; pavé (vectoriel) -> (vector) pad ; Coins -> Corners
- Taille -> Size ; Hauteur -> Height ; Rotation -> Rotation ; Mouvement -> Motion ; Un tour en -> One cycle in ; Dessiner -> Draw
- Cercle Circle, Infini Infinity, Losange Diamond, Carré Square, Triangle Triangle, Ricochet Bounce, Hasard Random, Dessinée Drawn
- Enr. le jeu -> Rec performance ; Enr. les mouvements -> Rec motion ; Enregistrer une prise -> Record a take ; Mode montage -> Arrange mode ; montage -> arrangement ; prise -> take ; clip -> clip ; règle -> ruler ; tête de lecture -> playhead ; aimant -> snap
- Conditions : Aucune None, FILL, NON FILL -> NOT FILL, PRÉ PRE, NON PRÉ NOT PRE, VOISIN NEIGHBOUR, NON VOISIN NOT NEIGHBOUR, 1ER 1ST, NON 1ER NOT 1ST
- Vélocité Velocity ; Durée Duration ; Décalage (d'un pas) Offset ; Probabilité Probability ; Répétitions Repeats ; Flam Flam
- Longueur Length ; Pas (fin) Steps (end) ; Vitesse Speed ; Division Division ; Sens Direction ; Octaves vues Visible octaves
- mes. (mesure) -> bar(s) : « 1 mes. » -> « 1 bar », « 2 mes. » -> « 2 bars », « # mes. » -> « # bars » ; temps -> beat(s)
- Préréglages -> Presets ; Macros -> Macros ; Modulations -> Modulations ; source -> source ; profondeur -> depth
- Retours -> Returns ; Principal -> Master ; Groupe -> Group ; envoi -> send ; panoramique -> pan ; coupure (mute) -> mute ; solo -> solo
- Coupure (filtre) -> Cutoff ; Résonance -> Resonance ; Enveloppe -> Envelope ; Attaque Attack ; Déclin Decay ; Maintien Sustain (ou Hold selon le contexte : « Maintien VCA » = « VCA hold ») ; Relâchement Release ; Saturation Drive/Saturation ; Accord (oscillateur) Tune ; Désaccord Detune
- Notes de musique françaises -> anglaises : Do C, Ré D, Mi E, Fa F, Sol G, La A, Si B (« Fa# » -> « F# », « Do1 » -> « C1 »)
- Échantillon -> Sample ; Charger -> Load ; Enregistrer (fichier) -> Save ; Ouvrir… -> Open… ; Nouveau projet vide -> New empty project ; Projet de démonstration -> Demo project ; Comme modèle -> As template

Règles :
- Garder EXACTEMENT les marqueurs {1}, {2}… et # (nombre), la ponctuation, les symboles (▶ ■ ● ◀ ⇄ ✎ ✕ × · → … « »),
  les espaces de début/fin, la casse générale (MAJUSCULES restent en majuscules).
- « » peuvent devenir " " en anglais. Pas de point final ajouté ou retiré.
- Noms propres, noms de sons d'usine, noms de produits / marques, sigles (LFO, VCA, VCF, MIDI, BPM, FM, AM, PD, ADSR, EQ…) : inchangés.
- Noms d'instruments ou d'effets génériques français (« Basse acide », « Machine électronique ») : les traduire (« Acid bass », « Electronic kit »).
- Texte qui n'est pas du français (déjà anglais, identifiant, nom propre) : le recopier tel quel.
- Rester court : une étiquette de bouton reste une étiquette.
